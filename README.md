# 🛡️ Smart-PAN Hub: Edition X
**The Ultimate Neon-Mesh Network Dashboard**

Edition X is a high-performance system controller and mesh identity manager built with Flutter. It features a unique "Bhai Mode" AI, hardware optimization tools, and privacy-focused Ghost Shield technology.

## 🚀 Key Features
* **Mono Robot Assistant:** Integrated UI mascot for system status.
* **Ghost Shield:** Invisible privacy overlays and encrypted storage.
* **AI Knowledge Base:** Hybrid Perplexity/ChatGPT interface (No API key needed).
* **Hardware Control:** Real-time RAM cleaning, System cooling, and Battery monitoring.
* **Mesh Identity:** Hardware-based PAN-ID generation.

## 🛠️ Tech Stack
* **Framework:** Flutter (Dart)
* **Architecture:** Modular Logic (14+ Interconnected Engines)
* **Theme:** Neon Glassmorphism

## 📁 Project Structure
- `lib/`: Core logic and UI files.
- `pubspec.yaml`: Project dependencies.
- `assets/`: UI Assets (Mascot & Icons).
